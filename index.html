Turn an image generator into a
general-purpose perception model.

Open Vision Banana fine-tunes open-weight FLUX.2 Klein 4B and 9B Base image generators on public data. The same model generates an RGB image for segmentation or geometry, then a deterministic decoder reads out the prediction. No task-specific prediction heads or losses are added.

A central finding

Test-Time Scaling for Vision Models

The model often finds the right regions but assigns the wrong colors. Repeating predictions with different color legends and voting on the decoded labels improves accuracy without additional training.

  1. 1

    Change the color legend

    Request the same categories with different color assignments.

    Pass 1RoadCar
    Pass 2RoadCar
  2. 2

    Predict and decode

    The same OVB model generates each image. Decode colors into common class labels.

    Purple→RoadPass 1
    Yellow→RoadPass 2
  3. 3

    Vote on the labels

    For each pixel, keep the category selected by the most decoded predictions.

    Majority→Road
Cityscapes · 9B · zero-shot65.4 → 74.06mIoU, first pass → peak vote (27, 28, or 30 passes)
COCO-Object · 9B · non-zero-shot44.9 → 59.3mIoU, first pass → 90-pass vote

The gain comes from correcting color binding.

Voting improves label accuracy while region quality stays nearly unchanged. On COCO-Object, wrong-class foreground pixels fall from 19.0% to 10.3% over 90 passes.

WHAT MAKES THE RECIPE WORK

Designing Generative Perception Models

Three takeaways from studying target encoding, training data, and model adaptation.

01
RGB interface

How labels map to colors matters.

Training with a fixed color legend yields 54.3 mIoU on Cityscapes, but only 7.1 when the colors change. Randomized assignments teach the model to follow the prompt.

02
Multi-task recipe

Balance performance across tasks.

More data or longer training can help one task while hurting another. The final recipe balances segmentation, geometry, and retained generative abilities.

03
Model adaptation

Adapt more of the backbone.

Tuning only the last few transformer blocks performs poorly. Strong perception requires adapting a substantial fraction of the backbone.

Open by construction

A recipe others can inspect, reproduce, and extend.

Built with public base models and datasets. We release training and evaluation code alongside model weights, including intermediate and ablation checkpoints.
